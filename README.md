# Trial Assistant - 检测业务流程自动化 Multi-Agent 平台

基于 LangGraph 的企业检测业务流程自动化智能体应用平台，实现知识问答、检测报价、设备预约、报告生成等复杂业务的智能化处理。
（部分工具需要对接原有LIMS接口）。
## 项目简介

本项目旨在解决企业内部大量业务系统无法被大模型直接调用的问题，通过 MCP 协议将企业内部能力标准化封装，让 Agent 能够自主选择和调用业务工具，实现检测业务流程的自动化处理。

## 核心功能

- **知识问答**：基于知识库的智能问答服务
- **检测报价**：自动化检测项目报价计算
- **设备预约**：试验设备预约管理
- **报告生成**：检测报告自动生成
- **Human-in-the-Loop**：关键业务节点人工确认机制

## 技术栈

- **框架**: Python 3.12+, LangGraph, LangChain
- **API**: FastAPI
- **向量数据库**: Milvus
- **消息队列**: RabbitMQ
- **缓存**: Redis
- **数据库**: PostgreSQL
- **容器化**: Docker
- **协议**: MCP (Model Context Protocol)

## 核心特性

### 1. 多智能体编排
基于 LangGraph StateGraph 设计状态驱动的多智能体协作流程，实现任务规划、意图路由、业务执行及结果汇总的完整闭环。

### 2. 意图路由
独立的 Intent Router Agent 根据用户意图动态选择业务 Agent，实现职责解耦和独立扩展。

### 3. 工具调用优化
基于 Function Calling 绑定独立 Tool 集合，结合 Pydantic 定义 Tool Schema，提升工具调用稳定性。

### 4. 状态持久化
基于 LangGraph Checkpointer 与 PostgreSQL 实现 Agent 状态持久化，支持工作流中断恢复、跨节点上下文共享。

### 5. MCP 协议集成
通过 MCP 协议将知识检索、LIMS 接口等能力封装为标准 Tool，实现业务能力与 Agent 解耦。

### 6. Human-in-the-Loop
在关键业务节点通过 Interrupt 暂停执行，支持参数补全和高风险操作确认，提高业务执行准确性。

### 7. 知识自动更新
基于 RabbitMQ 的异步更新机制，文档新增后自动触发解析、切片、向量化及入库流程。

## 快速开始

### 环境要求

- Python 3.12+
- Docker & Docker Compose

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
# 使用 Docker Compose 启动所有服务
docker-compose up -d

# 启动应用
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

### API 文档

启动服务后访问：http://localhost:8000/docs

## 核心价值

- **业务流程智能化**：将复杂业务拆分为多个专业 Agent 协同完成
- **工具调用准确性**：通过优化 Tool 描述、参数校验提高调用准确率
- **快速扩展能力**：新增业务能力只需开发对应 MCP Server
- **高安全性**：Human-in-the-Loop 机制降低业务误操作风险
- **低维护成本**：知识库自动更新减少人工维护
